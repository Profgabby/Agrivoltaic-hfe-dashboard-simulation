# Experimental Design and Claim Boundaries

## Purpose

The application is an interactive experimental prototype for examining human decision performance while interpreting designed agrivoltaic crop–water–energy dashboard scenarios.

## Experimental factor

The current primary factor is dashboard information load with three authored conditions: Low, Medium, and High. Three scenarios are provided for each condition.

## Recorded outcomes

- **Decision accuracy:** correct/incorrect relative to an authored scenario answer key.
- **Response time:** elapsed browser time from decision-stage presentation to response.
- **Subjective workload:** six 1–10 ratings inspired by NASA-TLX dimensions. The current composite is unweighted and is not claimed to reproduce the complete standard NASA-TLX procedure.
- **Situational-awareness probe accuracy:** one authored post-decision probe per scenario. These probes are SAGAT-inspired; the application does not claim a complete validated SAGAT protocol.

## Stimulus provenance

Scenario dashboard values and trend sequences are authored experimental stimuli. They are not field measurements. They currently have no external sensor, weather, database, or validated physical-model provenance.

## Current ordering

Trials are presented in fixed order: L1, L2, L3, M1, M2, M3, H1, H2, H3. Therefore condition is confounded with presentation order and potentially with learning and fatigue.

## Interpretation boundary

The application can demonstrate that a software workflow records the defined measures. It cannot, without a properly designed and conducted study, establish that one interface condition improves decision accuracy, workload, situational awareness, response time, crop performance, water use, energy performance, or operational outcomes.

## Human-subject boundary

This repository does not document or assert IRB approval, participant recruitment, informed consent, or completed human-subject data collection. Those requirements belong to an approved study protocol if/when the prototype is used for human-subject research.

## Planned methodological strengthening

Future research versions should define the study population, hypotheses, randomization/counterbalancing scheme, training trials, sample-size rationale, exclusion/missing-data rules, statistical analysis plan, validated measurement procedures, and scientific provenance for scenario thresholds and answer keys.
